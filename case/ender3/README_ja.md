# ALT60ケース Ender-3左右分割版

`case/original` のFIX済み原寸マスターを変更せず、Ender-3で出力できるようにトップとボトムを中央で左右分割した派生版です。

- トッププレートとボトムケースは左右2分割、合計4パーツです。
- 中央4本のM2.5ネジと完全なネジ受けを最優先し、丸棒・穴は位置合わせの補助とします。
- 独立した台座・柱・ブロックは作らず、底板と前後側壁へ横向きの丸棒と穴を直接形成します。
- 接手は前壁2本、底面6本、後壁2本の合計10本です。
- 丸棒を左・右から交互に一体成形し、反対側には対応する横穴を設けています。
- 丸棒は直径3.2 mm、差し込み長8.0 mm、穴は直径3.5 mm、深さ9.0 mm、先端面取り0.5 mmです。
- 通常の底厚2.5 mmは分割線付近で6 mm、通常の壁厚3 mmは前後壁の分割線付近で6 mmへ増厚します。
- 底板の丸棒・穴の中心は増厚後6 mmの板厚中央、底面からZ=3.0 mmです。前後壁の丸棒・穴も増厚後6 mmの壁厚中央へ置きます。
- 増厚範囲は中央から左右20 mmで、左右16〜20 mmの範囲を斜面にして滑らかにつなぎます。
- 補強は内側だけに加え、ケース外形は変更しません。
- 外枠の外側へ出る突起や別体部品はありません。
- 分割部は0.30 mmの組立クリアランスを設けています。
- 中央部の前後に左1本・右1本ずつ、合計4本のM2.5縦ネジを配置しています。
- ネジ位置は X=-8/+8 mm、Y=-45/+45 mmです。
- トップ側にはM2.5通し穴と局所補強、ボトム側には欠けない完全なネジ受けを設けています。
- トッププレートから垂直にネジを締め、左右ボトムを同時に固定します。
- 全出力パーツは最大外寸200 mm未満であることを自動検査します。

組立時は左右ボトムを同じ高さに合わせ、10本の丸棒を対応する穴へ水平方向から同時に差し込みます。その上に左右トップを載せ、中央4本のM2.5ネジを先に締めてから外周ネジを締めます。初回は直径差0.3 mmで試し刷りし、プリンタの実寸に応じて `SOCKET_D` を調整してください。
